<Steps>
  <Step title="Get an API key">
    Create a key in the [Geko console](https://app.geko.sh). Keys look like `sk-tokay-…`. Keep it server-side — treat it like a password. New accounts get **$1.00 of free credits**, and one key covers both directions.

    ```bash
    export GEKO_API_KEY=sk-tokay-...
    ```
  </Step>

  <Step title="Make a sound">
    Pick whichever feels natural — all four do the same thing.

    <CodeGroup>
    ```bash CLI
    # no code, no install
    npx @gekoai/sdk say "Сәлеметсіз бе!" --voice Aigerim -o hello.wav
    ```

    ```ts SDK
    import { Geko } from "@gekoai/sdk";
    import { writeFile } from "node:fs/promises";

    const geko = new Geko({ apiKey: process.env.GEKO_API_KEY });

    const audio = await geko.tts.create({
      text: "Сәлеметсіз бе!",
      voice: "Aigerim",
    });

    await writeFile("hello.wav", Buffer.from(audio));
    ```

    ```python Python
    import os, requests

    res = requests.post(
        "https://geko--tokay-serve-web.modal.run/v1/tts",
        headers={"Authorization": f"Bearer {os.environ['GEKO_API_KEY']}"},
        json={"text": "Сәлеметсіз бе!", "voice": "Aigerim"},
    )
    res.raise_for_status()
    open("hello.wav", "wb").write(res.content)
    ```

    ```bash curl
    curl -X POST https://geko--tokay-serve-web.modal.run/v1/tts \
      -H "Authorization: Bearer $GEKO_API_KEY" \
      -H "Content-Type: application/json" \
      -d '{"text":"Сәлеметсіз бе!","voice":"Aigerim"}' \
      --output hello.wav
    ```
    </CodeGroup>

    `hello.wav` is 24 kHz, 16-bit PCM mono. Play it:

    ```bash
    afplay hello.wav   # macOS
    aplay hello.wav    # Linux
    ```
  </Step>

  <Step title="Read it back">
    Now the other direction — send that same file back and get the text.

    <CodeGroup>
    ```bash CLI
    npx @gekoai/sdk transcribe hello.wav
    # сәлеметсіз бе
    #   1.2s audio · 3 credits · 18.5× realtime
    ```

    ```ts SDK
    import { readFile } from "node:fs/promises";

    const { text, audio_seconds, credits_charged } = await geko.stt.transcribe({
      audio: await readFile("hello.wav"),
      filename: "hello.wav",
    });

    console.log(text); // сәлеметсіз бе
    ```

    ```bash curl
    curl -X POST https://geko--seta-serve-transcriber-api.modal.run/v1/transcribe \
      -H "Authorization: Bearer $GEKO_API_KEY" \
      -H "Content-Type: application/octet-stream" \
      -H "x-filename: hello.wav" \
      --data-binary @hello.wav
    ```
    </CodeGroup>

    That's the whole API — text in, audio out, audio in, text out. Same key, [same balance](/billing).
  </Step>
</Steps>

## Install the SDK

```bash
npm install @gekoai/sdk
```

The SDK has **no runtime dependencies** and ships both ESM and CommonJS with types. Requires Node 20+ (or Deno / Bun / modern browsers).
